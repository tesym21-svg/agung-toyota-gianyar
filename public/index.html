📋 Panduan Setup Integrasi Google Spreadsheet (2-Arah)

🚀 Cara Pasang dalam 3 Menit (Sama persis seperti Accu Care):

  1. Buka Google Spreadsheet baru di Google Drive Anda (beri nama misal: Database Agung Toyota Gianyar).
  2. Klik menu atas: Ekstensi (Extensions) → Apps Script.
  3. Hapus semua teks yang ada di editor Apps Script, lalu salin seluruh kode di bawah dan tempel di sana.
  4. Klik ikon 💾 Simpan (Save) (Ctrl+S).
  5. Klik tombol biru Terapkan (Deploy) → Penerapan baru (New deployment) di kanan atas:
    • Klik ikon roda gigi di samping "Pilih jenis" → pilih Aplikasi Web (Web app).
    • Deskripsi: Agung Toyota API
    • Jalankan sebagai (Execute as): Saya (email Anda)
    • Yang memiliki akses (Who has access): Siapa saja (Anyone) (PENTING agar web app dapat membaca & menulis data)
  6. Klik Terapkan (Deploy), klik Berikan Akses (Authorize access) dengan akun Google Anda, lalu salin URL Aplikasi Web (yang berakhiran /exec).
  7. Kembali ke aplikasi ini, tempelkan URL tersebut ke kolom URL Web App Google Apps Script lalu klik "💾 Simpan & Hubungkan". Selesai! Data Anda langsung tersambung 2-arah.
